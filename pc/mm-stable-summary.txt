- "mm: make VMA flag semantics explicit, eliminate VM_SPECIAL"
  (Lorenzo Stoakes (ARM)):

  Replace VM_SPECIAL and assorted raw flag tests with helpers which say
  whether a mapping is managed by core MM, backed by it, fixed or
  mergeable. Enforce the mmap flag rules and convert the affected drivers,
  so driver mappings and ordinary memory no longer rely on the same
  ambiguous special-case tests.

- "support kselftest on nommu platform" (Hajime Tazaki):

  Add opt-in mmap and mremap selftests for NOMMU systems. Teach the runner
  to recognize NOMMU and avoid its fork-dependent timeout command, and
  document how to build and run the tests with a suitable toolchain.

- "mm/collapse: separate a collapse from its callers"
  (Kiryl Shutsemau (Meta)):

  Separate huge-page collapse from the decisions made by its callers. Pass
  an explicit policy instead of testing whether khugepaged called, and
  split page-table scanning from collapse with the mmap_lock drop in one
  place. This makes the interface and locking easier to follow.

- "mm: implement and use vma_has_anon_rmap(), silence KCSAN"
  (Lorenzo Stoakes (ARM)):

  Give callers a common helper for checking whether a VMA has an anonymous
  reverse mapping. Document the locking and recheck rules, annotate the
  intentional concurrent reads for KCSAN, and convert the core MM callers
  and comments to use the clearer interface.

- "mm/sparse: remove SECTION_MARKED_PRESENT and further cleanups"
  (David Hildenbrand (Arm)):

  Remove SECTION_MARKED_PRESENT and use the early-section flag during boot
  instead. Simplify sparse memory initialization and section metadata
  handling, and clean up the related PFN validity checks and debugger
  support.

- "sh: remove NUMA and SPARSEMEM support" (Mike Rapoport (Microsoft)):

  Remove SuperH's NUMA and SPARSEMEM machinery. The small extra memory
  banks which justified it have been unavailable to core MM since the
  NO_BOOTMEM conversion, leaving the kernel with the code and data overhead
  but none of the intended benefit.

- "mm: Unify device DAX and HugeTLB vmemmap population paths"
  (Muchun Song):

  Use the common vmemmap population path for device DAX and HugeTLB,
  including their shared tail pages. Remove the duplicate generic DAX path
  and its extra arguments and flags. Keep the architecture-specific powerpc
  radix implementation in place.

- "kselftest: mm: fix some failure of split_huge_page_test" (Yeoreum Yun):

  Fix intermittent huge-page split test failures caused by khugepaged
  collapsing the pages again. Use pagemap and page flags to check mappings
  and folios, avoiding assumptions about VMA boundaries which fail when
  glibc has already enabled THP for an allocation.

- "memcg: move memcgid refcount to objcg to unpin dying memcgs"
  (Bingfang Guo):

  Let dying memory cgroups go away even when swapped-out shmem still holds
  their private IDs. Move the ID references to objcgs, which can be
  reparented, and keep swap charges and RCU protection straight when an ID
  resolves to a live ancestor.

- "mm/truncate: fix data loss when truncating straddling large folios"
  (Zhang Yi):

  Preserve valid data outside a truncation or hole-punch range when a large
  folio straddles its boundary. Fix a folio lookup race and make split
  failures report exactly what can be discarded. Also handle minimum folio
  orders for the forthcoming ext4 iomap buffered I/O path.

- "mm/damon: introduce damos quota goal target metric complement flag"
  (SJ Park):

  Let DAMOS quota goals use the complement of an existing metric. This lets
  a memory-utilization metric also express a free-memory goal without
  adding a separate metric for every inverse relationship. Expose the flag
  through sysfs and add documentation and tests.

- "arm64/mm: Standardize printing for pgtable entries" (Anshuman Khandual):

  Use the generic page-table value formatter for arm64 diagnostics, ready
  for wider entries when those arrive. Move the safe-PTE-update check out
  of the header so the generic helper can be used without introducing an
  include cycle.

- "mm: kmsan: fix iounmap metadata teardown" (Dima Koziuk):

  Free KMSAN's ioremap metadata correctly on iounmap and on partial
  allocation failures. Keep the mappings available until their backing
  pages have been found and freed, then remove them and flush the TLB.
  Share the cleanup so failed mappings do not leak metadata either.

- "mm/damon/core: preserve quota state when constructing schemes"
  (Karl Mehltretter):

  Preserve a running DAMOS scheme's quota state when constructing temporary
  schemes to validate parameter updates. Previously even a rejected update
  could reset accounting and let the scheme exceed its quota window. Add
  tests for construction and accepted and rejected updates.

- "mm/vmalloc: fix vmalloc_dump_obj VA lookup" (Ye Liu):

  Make vmalloc_dump_obj() find allocations for addresses in their last page
  and for allocations spanning vmap zones. Round addresses down and search
  the other nodes when necessary, so these cases no longer disappear from
  the diagnostic output.

- "mm: various (urgent?) fixes" (David Hildenbrand (Arm)):

  Fix a collection of mmap and hugetlb failures: leaked commit charges,
  folio use-after-free, wrong-address unmapping, stuck locks and endless
  write faults. Preserve reservations across failed mremap operations and
  handle leftover userfaultfd bits without hanging the fault path. These
  bugs can cause allocation failures, data loss and kernel crashes.

- "maple_tree: fix maple_range_64 crashes in RCU mode" (Dimitris Charisis):

  Fix RCU destruction of maple_range_64 nodes so metadata is not mistaken
  for a child pointer and a valid pointer is not cleared as metadata. This
  avoids double frees and invalid accesses, and adds a regression test. No
  current in-tree user uses this node type in RCU mode.

- "mm: fix hugetlb NR_HUGETLB accounting on folio migration" (Hongfu Li):

  Fix hugetlb accounting across migration so /proc/vmstat no longer loses
  pages and memory.numa_stat attributes them to the right node. Account
  migration targets and memfd preallocation when the folios are obtained,
  and move the per-node memcg statistics with the charge.

- "mm/damon: fix a minor bug, clean code, and add a test" (SJ Park):

  Fix DAMON's region-age calculation on 32-bit systems, where overflow made
  old regions look young. Use the common hugetlb folio acquisition helper
  and add a regression test for the previously fixed last-region skipping
  bug.

- "mm/damon/core: cleanup code, reduce stack usage, and add kunit"
  (SJ Park):

  Reduce kdamond's stack usage and remove unused DAMOS enumerators. Add
  deterministic tests for PSI quota goals, including their initial
  unmeasured state, so the results do not depend on the test machine's
  current memory pressure.

- "mm/damon: fix the temporal goal tuner's size quota conversion"
  (Donggeun Yoo):

  Bound the temporal tuner's size-quota conversion so multiplication cannot
  wrap and produce a bogus effective quota. On 32-bit machines this could
  leave a scheme doing no work while its goal remained unmet. Add coverage
  for the conversion boundaries.

- "Don't use GFP_DMA when calling dma_alloc_coherent" (Baoquan He):

  Remove redundant GFP_DMA flags from coherent DMA allocation calls in a
  number of drivers. The DMA API already chooses the allocation zone from
  the device's DMA limits and ignores this flag, so carrying it around only
  encourages more copies of the same mistake.

- "kselftest: mm: fix intermittent failure khugepaged test" (Yeoreum Yun):

  Make the khugepaged selftest report failures from its child processes
  instead of quietly passing them. Prevent background collapse from racing
  the test's own checks, which caused intermittent failures in the swap and
  shared-page cases.

- "MAINTAINERS: cover all hugetlb headers under HUGETLB SUBSYSTEM"
  (Enze Li):

  Make the hugetlb MAINTAINERS entry cover all hugetlb headers, so
  get_maintainer.pl finds the right people for headers it previously
  missed. Use a glob to cover future additions too, and label the closing
  include guard in hugetlb_cgroup.h.
