Subject: mm/mempolicy: return EINVAL if len overflows for set_mempolicy_home_node
Date: Tue, 21 Mar 2023 15:40:33 +0800

set_mempolicy_home_node() rounds len up to a multiple of the page size.  A
nonzero len within PAGE_SIZE - 1 of ULONG_MAX (ULONG_MAX itself, for
example) rounds to zero, and the syscall then returns 0 without setting
the home node of any VMA.  The caller is told that its request succeeded
when nothing was done.

Return -EINVAL when a nonzero len rounds to zero. 
set_mempolicy_home_node() already returns -EINVAL when start + len wraps,
and madvise() returns -EINVAL for the same len.

A len of zero is still a successful no-op, and the checks of start, flags
and home_node are still made first.  The only change for userspace is that
a call with such a len now fails with -EINVAL where it used to return 0.
