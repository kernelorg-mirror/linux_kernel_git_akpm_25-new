Subject: selftests/mm: allocate nr_pages based on pmd size for uffd pmd_move tests
Date: Thu, 12 Nov 2026 21:00:45 -0700

When executing the uffd-unit-test, the "move-pmd on anon" test will fail
on aarch64+64k with a segmentation fault because the initial allocated
memory region is too small.  This only happens with the move-pmd* tests
because the architecture base page size is still utilized even though the
memory region is specific to the size indicated by the pmd.

Patch 9f5c2aec3388 ("selftests/mm: fix uffd move-pmd test crash on 64K
base page systems") implements an initial fix to the segmentation fault by
skipping the test if the allocated memory region is not large enough for
the number of pages x page size requested.  Since this will skip over the
aarch64+64k pmd tests, this patch is intended to resolve the problem with
64k pages by pre-allocating the memory region with 2x the pmd page size
(for area_src and area_dst) for only the move_pmd tests by using the
uffd_test_case_ops pre_alloc hook.
