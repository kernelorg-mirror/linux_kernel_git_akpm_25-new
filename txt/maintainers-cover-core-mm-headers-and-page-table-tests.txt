Patch series "MAINTAINERS: assign uncovered MM files to components".

Add missing MM component entries for headers, library implementations
and tests, and files under mm/.  Keep existing entries for these files,
including their maintainers and reviewers.

Assign files with a clear home to that component.  Shared interfaces
appear under two or three components; files without a clear component
are labeled unclaimed and placed under MISC.  Preserve existing file
patterns and non-MM coverage.

This series adds file assignments without removing any existing
assignments.  Renamed entries retain all existing file patterns,
maintainers and reviewers.

Many files remain under MEMORY MANAGEMENT - MISC.  These will be moved
to appropriate components in a later series.  Documentation/ coverage
will also be addressed in a later series.

A follow-up series will give the contiguous memory allocator (CMA) its
own MM component, moving include/linux/cma.h, mm/cma.c, mm/cma.h,
mm/cma_debug.c and mm/cma_sysfs.c out of MISC.  This series leaves their
existing assignments unchanged.

Create MEMORY MANAGEMENT - USER ACCESS for the user-access interfaces,
using the maintainer, reviewers, status and tree from MEMORY MANAGEMENT
- CORE.  Assign the page-table interfaces to MEMORY MANAGEMENT - MEMORY
MAPPING.

Patch 10 renames MAPLE TREE and XARRAY to MEMORY MANAGEMENT - MAPLE TREE
and MEMORY MANAGEMENT - XARRAY and moves them among the MM entries.
These files were originally used only by MM, they remain primarily used
by MM and their maintainers are recognized members of the MM team.
Keep all existing contacts and file patterns in both entries.

Patch 11 renames KMEMLEAK to MEMORY MANAGEMENT - KMEMLEAK and moves it
between KASAN and KSM.  Keep Catalin Marinas as maintainer and add
linux-mm@kvack.org.  Keep all existing file patterns.

Patch 12 renames KFENCE and KMSAN to MEMORY MANAGEMENT - KFENCE and
MEMORY MANAGEMENT - KMSAN.  Preserve all contacts and file patterns.
Also add MM review coverage for mm/memfd_luo.c under SHARED MEMORY
(SHMEM/TMPFS/MEMFD).  LIVE UPDATE remains its primary home and its
existing entry is unchanged.

Files without a clear MM component are labeled unclaimed and assigned
to MEMORY MANAGEMENT - MISC.  Files assigned to more than one MM
component are marked as shared.  Existing entries for these files,
such as LIBRARY CODE and USERSPACE COPYIN/COPYOUT (UIOVEC), are unchanged.

The below accounting separates files lacking a specific entry from files
receiving additional MM coverage.  Existing owners remain responsible;
the added MM entries identify additional reviewers.  Existing
MAPLE TREE, XARRAY, KMEMLEAK, KFENCE and KMSAN file patterns move with
their entries and are not repeated below.

This patch (of 12):

Cover page-table interfaces, mapping tests and user-memory access helpers.
Create MEMORY MANAGEMENT - USER ACCESS with the existing CORE contacts,
status and tree.  The page-table semantics test is distinct from PAGE TABLE
CHECK; the KUnit allocation helper creates userspace mappings. Also assign
the /dev/mem access helper to MEMORY MAPPING, hardened usercopy and I/O
iterator interfaces to USER ACCESS, and the interval-tree template used by
mm/interval_tree.c to RMAP (REVERSE MAPPING). Existing file assignments
remain unchanged.
