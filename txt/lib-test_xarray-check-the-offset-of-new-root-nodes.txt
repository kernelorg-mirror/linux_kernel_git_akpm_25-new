Subject: lib/test_xarray: check the offset of new root nodes
Date: Fri, 23 Oct 2026 21:43:44 -0400

Patch series "xarray: initialise the offset of a new root node", v2.

An RCU XArray walker can read a stale root offset just before another
thread grows the tree and links that root beneath a new one.  The walker
can then return an entry with the wrong index or skip entries.  Check the
root offset after slab reuse and initialize it on allocation.


This patch (of 2):

Free XArray nodes whose offsets are nonzero, then check that roots
created by xas_create() and xas_expand() have offset zero. An old
root with a stale offset can make a concurrent iterator resume in
the wrong slot after expansion.
