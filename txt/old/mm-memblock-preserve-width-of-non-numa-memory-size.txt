Subject: mm/memblock: preserve width of non-NUMA memory size
Date: Fri, 20 Nov 2026 11:28:00 -0800

memblock_validate_numa_coverage() shifts the count of pages without
a valid node ID in unsigned long. On a 32-bit NUMA kernel, 4 GiB
of such memory wraps to zero, allowing an invalid firmware node map
to pass validation. The error message can also report a wrapped size.

Compute the byte count in u64 before both the comparison and the
diagnostic. The threshold remains in bytes.
