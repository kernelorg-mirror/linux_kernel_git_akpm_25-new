Subject: MAINTAINERS: cover address layout and shared mapping permissions
Date: Sun, 01 Nov 2026 18:30:41 -0800

Cover mmap/brk address randomization under MEMORY MAPPING.  Share the
mapping-permission interface with EXECMEM and VMALLOC, in addition to its
MEMORY MAPPING assignment in patch 1.

Add mm/memfd_luo.c to SHARED MEMORY (SHMEM/TMPFS/MEMFD) for memfd live
update support.  LIVE UPDATE remains its primary home; this adds MM review
coverage for its memfd handling.  Keep its existing LIVE UPDATE entry and
include that entry's maintainers in Cc.

Add the following file assignments:

MEMORY MANAGEMENT - EXECMEM
        include/linux/set_memory.h

MEMORY MANAGEMENT - MEMORY MAPPING
        include/linux/elf-randomize.h

MEMORY MANAGEMENT - SHARED MEMORY (SHMEM/TMPFS/MEMFD)
        mm/memfd_luo.c

MEMORY MANAGEMENT - VMALLOC
        include/linux/set_memory.h
