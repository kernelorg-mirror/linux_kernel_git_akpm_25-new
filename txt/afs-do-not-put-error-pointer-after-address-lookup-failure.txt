Subject: afs: don't put an error pointer after a failed address lookup
Date: Mon, 23 Nov 2026 09:45:43 -0800

afs_vl_lookup_addrs() can return an error pointer when the VL server
cannot supply addresses for a fileserver.  afs_lookup_server() saves the
error and jumps to create_failed, but leaves the error pointer in alist. 
The common exit path passes it to afs_put_addrlist(), which dereferences
it and oopses.

This happened while mounting a local AFS volume: the VL_GetAddrsU address
lookup failed and afs_vl_lookup_addrs() returned -ENOMEDIUM.  Clear alist
after saving the error so the existing failure path can release the server
record and return the error without trying to put a nonexistent address
list.  A successful address lookup is still released by the common exit
path.
