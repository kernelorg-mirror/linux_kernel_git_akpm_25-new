From: Andrew Morton <akpm@linux-foundation.org>
Subject: kernfs: stay in RCU walk during path lookup
Date: Tue, 24 Nov 2026 22:00:14 -0800

In an emulated four-CPU guest, four processes calling stat() on
/sys/fs/cgroup/t/a/b/c/d/cgroup.procs went from 179,000 to 405,000 calls
per second.  access(R_OK) went from 194,000 to 533,000 and open()+close()
from 122,000 to 219,000.  One process calling stat() went from 65,000 to
126,000.  Paths under /sys/devices gained about as much, and a tmpfs path
of the same depth did not change.  The guest was QEMU without KVM, where
atomic operations are costly, so real hardware will gain less per CPU.
This has not been measured on real hardware or with more than four CPUs.

kernfs is the filesystem behind sysfs and cgroupfs.  A path lookup starts
in RCU walk, which takes no locks and no references.
kernfs_dop_revalidate() and kernfs_iop_permission() both return -ECHILD
when they are called in RCU walk, so every lookup under /sys leaves RCU
walk at its first kernfs component.  After that each component costs a
dentry reference, and each directory costs a down_read() of
kernfs_iattr_rwsem and a copy of the mode, owner, times and link count
into the inode, whether or not they have changed.  There is one
kernfs_iattr_rwsem for all of sysfs and one for each cgroup hierarchy.

kernfs_dop_revalidate() already takes no locks, so let it run in RCU walk.
It has to read ->d_inode once, because in RCU walk the dentry can lose its
inode at any time.  It also reads kernfs_super_info.ns, and an RCU walk
can still be inside a superblock which is being killed, so free the
kernfs_super_info with kfree_rcu().

kernfs_iop_permission() refreshes the inode from its kernfs_node and then
calls generic_permission(), which looks only at the mode and the owner.
So compare those in the inode with those in the node.  If they are the
same there is nothing to refresh, and the check can be made without the
lock, in RCU walk and in ref walk.  If they differ, do what was done
before: return -ECHILD in RCU walk, take the lock and refresh otherwise.

The comparison on its own is not enough.  chown() changes the uid and the
gid of the node and then those of the inode.  A check which compared
before the chown() and looked at the inode half way through it would see
the new uid with the old gid, and could allow what neither owner allows.
So chmod() and chown() are now made inside a write section of a new
per-root seqcount, still under kernfs_iattr_rwsem, and the lockless check
is a read section of it.  The reader never waits for a writer: if a write
section is running, or one started during the check, it falls back to the
lock.  That is why the raw seqcount operations are used and why the write
section is allowed to sleep.

kernfs_refresh_inode() still stores the mode and owner in the inode with
kernfs_iattr_rwsem held for read and no write section.  It copies them
from the node, which cannot change while that lock is held, so during a
lockless check it can only store the values which the check has just
found there.

With a test-only 100us delay between the uid and gid stores in
setattr_copy() and a 20us delay between the comparison and the check, a
directory of mode 0007 had its owner flipped between 1000:2000 and
2000:1000.  A process with uid 1000 and gid 1000 must always be refused a
lookup through it.  It was allowed in 77,677 of 722,434 lookups when the
seqcount was not rechecked, and in none of 700,728 with this patch.

->permission() no longer refreshes the times and link count of the inode
when it takes the lockless path.  ->getattr() refreshes them before it
reports them, as before.

Two things are not changed.  kernfs_iop_get_link() still returns -ECHILD
in RCU walk, so a lookup through a sysfs symlink, such as the entries of
/sys/class and of /sys/bus/*/devices, leaves RCU walk there.  And
->getattr() still takes kernfs_iattr_rwsem, so stat() takes it once per
call where it took it once per directory.

These numbers say that the patch helps and roughly where.  They do not
say by how much on real hardware.  The emulator makes every atomic
operation and lock expensive, which is why even one process gains so
much.  Nothing here shows what happens at 64 CPUs, which is where the
shared rwsem and the dentry references should hurt most.

not run with the delay.

Things you should know before merging:

- Not built or run: PREEMPT_RT, KCSAN, 32-bit, any other architecture,
  SELinux or any other LSM.  The LSM permission hook now runs in RCU walk
  for kernfs inodes, as it does for other filesystems.

- The kfree_rcu() in kernfs_kill_sb() is there by reading, not because a
  test failed.  I ran Bdbg with that line put back to kfree() for 90
  seconds of kt mnt (479 mounts) and KASAN reported nothing, so the test
  does not reach that window.

- Nothing here renames a kernfs node during a lookup.  cgroup2 has no
  rename and I did not set up a network device to rename.  The rename
  check in kernfs_dop_revalidate() is not changed, but it has not run in
  RCU walk under test.

- An earlier version of the patch disabled preemption in the write
  section.  setattr_copy() calls capable(), which can reach an LSM's
  audit code and so a sleeping lock on PREEMPT_RT, so I changed it to the
  raw seqcount operations.  The numbers above are from the final version.

- struct kernfs_root grows by a seqcount_t and struct kernfs_super_info
  by an rcu_head.  struct kernfs_node does not change.

- This is Greg's and Tejun's code and neither has seen it.

The test program, kt.c:

:/*
: * kt - kernfs path lookup tests
: *
: * kt perf OP NPROC SECS PATH...
: *	NPROC processes repeat OP (stat, access or open) for SECS seconds.
: *	Process i uses PATH[i % npaths].  Prints operations per second.
: *
: * kt perm DIR ITERS
: *	chmod() and chown() the cgroup directory DIR and check after each
: *	change that an unprivileged process sees exactly the new permission.
: *
: * kt race DIR SECS
: *	Flip the owner of DIR between (1000,2000) and (2000,1000), mode
: *	0007.  uid 1000/gid 1000 is denied in both states and allowed only
: *	if it sees a half-made change.  Counts lookups which were allowed.
: *
: * kt neg DIR ITERS
: *	mkdir()/rmdir() DIR/x and check that a lookup sees each change.
: *
: * kt churn DIR SECS
: *	mkdir/rmdir, chmod, chown, stat and access under DIR from several
: *	processes at once, for debug kernels.  Checks nothing itself.
: *
: * kt mnt MNT SECS
: *	Repeatedly mount sysfs on MNT from a new network namespace and
: *	lazily unmount it, while other processes walk into it.  For debug
: *	kernels: each round frees a superblock under the walkers.
: */

:static double now(void)
:{
:	struct timespec ts;
:
:	clock_gettime(CLOCK_MONOTONIC, &ts);
:	return ts.tv_sec + ts.tv_nsec / 1e9;
:}

:static void die(const char *what)
:{
:	perror(what);
:	exit(2);
:}

:struct shared {
:	volatile int go;
:	volatile int stop;
:	volatile unsigned long count[64 * 8];	/* one cacheline apart */
:	volatile unsigned long allowed;
:	volatile unsigned long denied;
:	volatile unsigned long other;
:};
:
:static struct shared *sh;
:
:static void drop_to(uid_t uid, gid_t gid)
:{
:	if (setgroups(0, NULL) || setgid(gid) || setuid(uid))
:		die("drop privileges");
:}

:static int do_perf(int argc, char **argv)
:{
:	const char *op = argv[0];
:	int nproc = atoi(argv[1]);
:	double secs = atof(argv[2]);
:	char **paths = argv + 3;
:	int npaths = argc - 3;
:	unsigned long total = 0;
:	double t0, t1;
:	int i;
:
:	if (npaths < 1 || nproc < 1 || nproc > 64)
:		return 2;
:
:	for (i = 0; i < nproc; i++) {
:		pid_t pid = fork();
:
:		if (pid < 0)
:			die("fork");
:		if (!pid) {
:			const char *path = paths[i % npaths];
:			volatile unsigned long *cnt = &sh->count[i * 8];
:			unsigned long n = 0;
:			struct stat st;
:			int fd;
:
:			while (!sh->go)
:				;
:			while (!sh->stop) {
:				if (op[0] == 's') {
:					if (stat(path, &st))
:						die(path);
:				} else if (op[0] == 'a') {
:					if (access(path, R_OK))
:						die(path);
:				} else {
:					fd = open(path, O_RDONLY);
:					if (fd < 0)
:						die(path);
:					close(fd);
:				}
:				*cnt = ++n;
:			}
:			_exit(0);
:		}
:	}
:
:	usleep(200000);
:	t0 = now();
:	sh->go = 1;
:	usleep((useconds_t)(secs * 1e6));
:	sh->stop = 1;
:	t1 = now();
:	for (i = 0; i < nproc; i++)
:		total += sh->count[i * 8];
:	while (wait(NULL) > 0)
:		;
:	printf("perf %s nproc=%d npaths=%d: %.0f ops/s\n", op, nproc, npaths,
:	       total / (t1 - t0));
:	return 0;
:}

:/* Run access(path) as uid/gid 1000 in a child; return 0 or errno. */
:static int access_as_user(const char *path)
:{
:	int status;
:	pid_t pid = fork();
:
:	if (pid < 0)
:		die("fork");
:	if (!pid) {
:		drop_to(1000, 1000);
:		_exit(access(path, F_OK) ? errno : 0);
:	}
:	waitpid(pid, &status, 0);
:	return WEXITSTATUS(status);
:}
:
:/* Keep the walk through @path hot in other processes. */
:static void start_walkers(const char *path, int n, int as_user)
:{
:	int i;
:
:	for (i = 0; i < n; i++) {
:		pid_t pid = fork();
:
:		if (pid < 0)
:			die("fork");
:		if (!pid) {
:			if (as_user)
:				drop_to(1000, 1000);
:			while (!sh->stop) {
:				if (!access(path, F_OK))
:					__sync_fetch_and_add(&sh->allowed, 1);
:				else if (errno == EACCES)
:					__sync_fetch_and_add(&sh->denied, 1);
:				else
:					__sync_fetch_and_add(&sh->other, 1);
:			}
:			_exit(0);
:		}
:	}
:}
:
:static void stop_walkers(void)
:{
:	sh->stop = 1;
:	while (wait(NULL) > 0)
:		;
:}
:
:static int do_perm(int argc, char **argv)
:{
:	const char *dir = argv[0];
:	int iters = atoi(argv[1]);
:	static const struct {
:		uid_t uid;
:		gid_t gid;
:		mode_t mode;
:		int want;
:	} steps[] = {
:		{ 0,    0,    0755, 0 },
:		{ 0,    0,    0700, EACCES },
:		{ 1000, 0,    0700, 0 },
:		{ 1000, 0,    0070, EACCES },
:		{ 0,    1000, 0070, 0 },
:		{ 0,    1000, 0007, EACCES },
:		{ 0,    0,    0007, 0 },
:		{ 0,    0,    0750, EACCES },
:		{ 2000, 1000, 0750, 0 },
:		{ 2000, 2000, 0750, EACCES },
:	};
:	unsigned long checks = 0, wrong = 0;
:	char path[512];
:	int i, s, got;
:
:	snprintf(path, sizeof(path), "%s/cgroup.procs", dir);
:	start_walkers(path, 2, 1);
:	start_walkers(path, 1, 0);
:
:	for (i = 0; i < iters; i++) {
:		for (s = 0; s < (int)(sizeof(steps) / sizeof(steps[0])); s++) {
:			if (chown(dir, steps[s].uid, steps[s].gid))
:				die("chown");
:			if (chmod(dir, steps[s].mode))
:				die("chmod");
:			got = access_as_user(path);
:			checks++;
:			if (got != steps[s].want) {
:				wrong++;
:				printf("perm: iter %d step %d: got %d want %d\n",
:				       i, s, got, steps[s].want);
:			}
:		}
:	}
:	stop_walkers();
:	if (chown(dir, 0, 0))
:		die("chown");
:	chmod(dir, 0755);
:	printf("perm: %lu checks, %lu wrong (walkers: %lu allowed, %lu denied, %lu other)\n",
:	       checks, wrong, sh->allowed, sh->denied, sh->other);
:	return wrong != 0;
:}

:static int do_race(int argc, char **argv)
:{
:	const char *dir = argv[0];
:	double secs = atof(argv[1]);
:	unsigned long flips = 0;
:	char path[512];
:	double end;
:
:	snprintf(path, sizeof(path), "%s/cgroup.procs", dir);
:	if (chown(dir, 1000, 2000) || chmod(dir, 0007))
:		die("setup");
:	start_walkers(path, 3, 1);
:
:	end = now() + secs;
:	while (now() < end) {
:		if (chown(dir, 2000, 1000) || chown(dir, 1000, 2000))
:			die("chown");
:		flips += 2;
:	}
:	stop_walkers();
:	if (chown(dir, 0, 0))
:		die("chown");
:	chmod(dir, 0755);
:	printf("race: %lu chowns, %lu lookups denied, %lu ALLOWED, %lu other\n",
:	       flips, sh->denied, sh->allowed, sh->other);
:	return sh->allowed != 0 || sh->other != 0;
:}

:static int do_neg(int argc, char **argv)
:{
:	const char *dir = argv[0];
:	int iters = atoi(argv[1]);
:	unsigned long wrong = 0;
:	char sub[512], path[512];
:	struct stat st;
:	int i;
:
:	snprintf(sub, sizeof(sub), "%s/x", dir);
:	snprintf(path, sizeof(path), "%s/x/cgroup.procs", dir);

:}

:static int do_churn(int argc, char **argv)
:{
:	const char *dir = argv[0];
:	double secs = atof(argv[1]);
:	char sub[512], path[512];
:	struct stat st;
:	int i;
:
:	for (i = 0; i < 6; i++) {
:		pid_t pid = fork();
:
:		if (pid < 0)
:			die("fork");
:		if (pid)
:			continue;
:
:		snprintf(sub, sizeof(sub), "%s/c%d", dir, i % 2);
:		snprintf(path, sizeof(path), "%s/c%d/cgroup.procs", dir, i % 2);
:		if (i >= 4)
:			drop_to(1000, 1000);
:		while (!sh->stop) {
:			switch (i) {
:			case 0:
:			case 1:
:				mkdir(sub, 0755);
:				if (chown(sub, 1000 * (rand() & 1), 1000))
:					break;
:				chmod(sub, rand() & 1 ? 0755 : 0700);
:				stat(path, &st);
:				rmdir(sub);
:				break;
:			case 2:
:				chmod(dir, rand() & 1 ? 0755 : 0711);
:				stat(path, &st);
:				break;
:			default:
:				access(path, R_OK);
:				stat(path, &st);
:				stat(sub, &st);
:				break;
:			}
:		}
:		_exit(0);
:	}
:	usleep((useconds_t)(secs * 1e6));
:	stop_walkers();
:	chmod(dir, 0755);
:	printf("churn: done\n");
:	return 0;
:}

:{
:	const char *mnt = argv[0];
