Subject: mm/memory: print full file offset in VMA diagnostic
Date: Fri, 20 Nov 2026 11:28:00 -0800

print_vma_addr() adds the VMA's file offset after shifting it
in unsigned long. On a 32-bit kernel, an instruction address in a
file mapping above 4 GiB can consequently be logged with a wrapped
file offset when the architecture prints fault information. This
affects the diagnostic, not the mapping itself.

Keep the file offset in u64 through the addition and print it with
the matching format specifier.
